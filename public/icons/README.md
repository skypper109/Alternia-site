# Dossier des icônes PWA

Placer ici les icônes de l'application pour le manifest PWA.

## Tailles requises

| Fichier | Taille | Usage |
|---------|--------|-------|
| `icon-72x72.png` | 72×72px | Android legacy |
| `icon-96x96.png` | 96×96px | Android |
| `icon-128x128.png` | 128×128px | Chrome |
| `icon-144x144.png` | 144×144px | Android |
| `icon-152x152.png` | 152×152px | iOS |
| `icon-192x192.png` | 192×192px | Android (maskable) |
| `icon-384x384.png` | 384×384px | Android |
| `icon-512x512.png` | 512×512px | Android (maskable) |

## Design recommandé

- Fond : #314999 (Bleu Royal ALTERNIA)
- Lettre "A" centrée en blanc, police serif
- Padding 15% autour du logo
- Format PNG avec transparence si possible
